# Editing Audio Matrix configuration

- `~/.config/audio-matrix/config.json` is the only live settings source. `config.yaml` is supported only as a legacy import or explicit input. The first import preserves the YAML as `config.yaml.before-json`; do not write ongoing settings to YAML.
- Validate live-format changes with `./gradlew run --args="--validate-config /path/to/config.json"`. Never store generated/runtime PipeWire IDs or process IDs in config.
- Keep stable device IDs and selectors; supported kinds are `name_equals`, `name_contains`, and `description_contains`. A device `name` is a display alias. Profile `default_output` and route `to` values may reference stable device IDs; preserve those IDs when changing a selector.
- Device roles are explicit optional values: `haptic_output`, `subwoofer`, `speaker`/`speakers`, or generic `output` for outputs; `input`, `microphone`, `accelerometer`, or `source` for inputs. A missing role is unassigned. Never infer `haptic_output` from a device name. Specialized modes validate paths: Haptic requires effects-only source paths and a `haptic_output`; Subwoofer requires a subwoofer branch/output, accepts music/subwoofer roots and warns when a path lacks a low-pass; Speaker requires a `speaker`/`speakers` output. Bus roles are `general`, `music`, `effects`, and `subwoofer`.
- Event Sound Studio streams use `application.id=io.github.ilyaandreev05.eventsoundstudio`. Keep them out of the general application catch-all. They stay on the isolated `audiomatrix_events` virtual sink until an exact application-ID route is configured.
- `engine.transition_ms` controls a linear fade on Audio Matrix-owned route playback nodes when rebuilding/clearing the graph; valid values are integers from 0 to 1000 ms. This smooths software route gain and does not limit amplifier or transducer power.
- An application, bus, route, or output device may reference an EQ chain as `dsp.route_chains.<id>` with `filters_ref`. App chains run per matching stream; output chains run once after route branches to that sink are mixed. Filter records are shared, so editing one affects every reference.
- High-pass and low-pass filters may set `slope_db_oct` to 6, 12, 18, 24, 36, or 48; the default is 12. Higher orders render as cascaded Butterworth sections. The `q` setting applies to 12 dB/oct; omit it for other slopes unless preserving external metadata.
- Config writes are atomic and guarded by a version/fingerprint check. If an external edit conflicts, reload and resolve it; never overwrite the external version silently.
- Never add fictional calibration measurements. Measurement WAV/CSV files remain separate assets referenced from JSON.
