# UI direction

Audio Matrix uses a compact desktop dashboard: a stable left navigation rail, one clear page title, plain-language device states, and cards/tables sized for GNOME desktop use. The visual direction is restrained Swiss minimalism with high-contrast light and dark themes; cyan marks active routing, amber marks a limitation or warning, and red is reserved for destructive/error states. Text labels remain visible next to every control, and the keyboard focus ring is never hidden.
