# Backup and restore

Use **Profiles → Backup and transfer** to export or restore a complete local config backup. Version 3 archives contain `config.json` with profiles, routes, buses, EQ and calibration metadata, plus each referenced `measurement_file` and `response_curve_file` under `data/`. `manifest.json` records SHA-256 digests for all files. Versions 1 and 2 with `config.yaml` remain importable.

The importer validates the manifest and config, checks every digest, rejects absolute and traversing paths, and caps the archive at 512 files and 512 MiB expanded size. It previews the profile, route and measurement counts before applying. Restore replaces `config.json` only after confirmation and after the config store's concurrent-edit check. Existing files are retained; identical measurements are reused and conflicting files are restored under `measurements/imported/` with their JSON reference updated.

The preview stage validates and stages the archive without applying it. On confirmation, the app offers a mapping dialog for imported selectors that match zero or multiple local devices; each can be mapped to a sink/source of the correct direction or left offline. Mapping updates the imported JSON selector. Saving the imported config can immediately apply matching device and stream volume/mute rules. An already-applied route graph refreshes from the imported config; if imported `apply_on_start` is true, routes can be applied immediately and on subsequent app launches. The system default output is not changed by the importer itself. Measurement files must be stored as relative paths inside the Audio Matrix config directory; arbitrary absolute paths are excluded from the archive.

The current archive manifest is version 3 and declares the config entry, application, config schema version, full-backup kind, and SHA-256 digests. Versions 1 and 2 migrate during preview. Future manifest versions, archives from another application, and manifest/config schema mismatches are rejected. This format restores the full config rather than selected profiles. A valid digest detects accidental file changes but does not identify the archive's author.
