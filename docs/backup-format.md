# Backup and restore

Use **Profiles → Backup and transfer** to export or restore a complete local config backup. The archive contains `config.yaml` with profiles, routes, buses, EQ and calibration metadata, plus each referenced `measurement_file` and `response_curve_file` under `data/`. `manifest.json` records SHA-256 digests for all files.

The importer validates the manifest and config, checks every digest, rejects absolute and traversing paths, and caps the archive at 512 files and 512 MiB expanded size. It previews the profile, route and measurement counts before applying. Restore replaces YAML only after confirmation and after the config store's concurrent-edit check. Existing files are retained; identical measurements are reused and conflicting files are restored under `measurements/imported/` with their YAML reference updated.

The preview stage validates and stages the archive without applying it. On confirmation, the app offers a mapping dialog for imported selectors that match zero or multiple local devices; each can be mapped to a sink/source of the correct direction or left offline. Mapping updates the imported YAML selector. Saving the imported config can immediately apply matching device and stream volume/mute rules. An already-applied route graph refreshes from the imported config; if imported `apply_on_start` is true, routes can be applied immediately and on subsequent app launches. The system default output is not changed by the importer itself. Measurement files must be stored as relative paths inside the Audio Matrix config directory; arbitrary absolute paths are excluded from the archive.

The current archive manifest is version 2 and declares the application, config schema version, full-backup kind, and SHA-256 digests. Version 1 manifests migrate during preview, including early archives that omitted the `kind` field. Future manifest versions, archives from another application, and manifest/config schema mismatches are rejected. This format restores the full config rather than selected profiles. A valid digest detects accidental file changes but does not identify the archive's author.
