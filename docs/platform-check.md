The app uses `pw-dump` snapshots plus its change monitor and `wpctl` for actual node volume/mute/default-output operations. Saved application rules apply volume and mute to discovered streams matching `application.process.binary` and/or `application.id`. JUnit covers process, app ID, and combined matching. For a live integration check, Audio Matrix ran under Xvfb with a temporary config matching a digital-silence `pw-play` stream whose properties were set to `application.process.binary=pw-play` and `application.id=org.example.AudioMatrixRuleTest`; the app applied volume 0.17 and mute. Direct `wpctl` volume/mute changes were also checked on a silent stream.

The route manager was exercised directly against PipeWire 1.6.2 with a 40-second digital-silence stream. The observed graph was `pw-play → Audio Matrix virtual sink → branch EQ → route loopback → shared output EQ → linked peak limiter → current analog sink`; applying the same configuration again retained the same links, an unavailable selector used its configured `system_default` fallback, and profile mode Off cleared the graph. Closing the manager restored both original stream links. After cleanup, no `audiomatrix_*` nodes remained and the default sink volume was still 0.51. This confirms graph creation and wiring on this session, not the EQ response or acoustic output. The native harness verifies that the limiter stays below its configured digital ceiling and attenuates another channel when a linked channel peaks. The DSP page now reads peak/RMS from the selected PipeWire sink monitor; input capture is off until explicitly enabled and PCM is not stored. Its headroom figure is a full-scale model with conservative positive-EQ and coherent-branch assumptions. It does not measure voltage, acoustic SPL, vibration, or amplifier power. Physical haptics/audio, fallback after unplugging a real device, PipeWire restart, smooth mode transitions, drift, measured response, and amplifier/transducer power remain unverified. The Routes screen exposes explicit Apply and Clear controls; direct stream transfer is disabled while that route graph is active.
