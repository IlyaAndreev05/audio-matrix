# Audio Matrix 0.4.2 release checklist (GNOME extension 21)

Дата: 23.10.2026. API моста остаётся v5, schema конфигурации — 11. Event Sound Studio 0.2.4 не пересобирается и не откатывается.

## Изменения

- Полная панель Audio Matrix перенесена в штатное подменю «Звуковой выход» и находится непосредственно перед секцией устройств. Скрывается только штатный список устройств; стрелка остаётся доступной и при единственном выходе, а заголовок, общий ползунок, разделитель, «Настройки звука», микрофон и плитки сохраняются. Отдельного блока в корневой сетке Quick Settings больше нет.
- Динамические входы микшера используют имя приложения, а не сгенерированный ID порта. Вход без актуальной live-привязки остаётся видимым, но неинтерактивным; при отсутствии имени показывается «Приложение недоступно». Уровень и mute изменяют вход микшера одной валидированной мутацией и подтверждают точную закреплённую цель; ошибка снимает pending и возвращает наблюдаемое значение.
- Реакция на общую громкость больше не ждёт 250 мс debounce топологии: изменения только уровней узлов объединяются за 5 мс, а защищённый level-only reconcile применяет лишь изменившиеся уровни шин и маршрутов. При любом сомнении выполняется полное согласование.
- Приватный end-to-end прогон принял один production-триггер `api_test` и дал ненулевой PCM на event sink, шине, выходе маршрута и виртуальном заднем sink. Это подтверждает программную доставку, но не физическую вибрацию.

## Измеренные результаты приватных прогонов

- Генерируемый вход микшера: уровень 0.35 подтверждён ACK, сохранён в JSON и не откатывается; PCM виртуального выхода изменился с 0.1000 до 0.0350, mute дал 0.00000, после переподключения сохранился тот же стабильный порт. Базовый прогон `26ff214` падает с `Mixer input no longer exists`.
- Панель: проверена в приватной headless-сессии GNOME Shell 50.1; скриншоты и журналы attach/reparent/rollback находятся в `build/gnome-menu-proof/`.
- Общая громкость, 20 samples: до исправления p50 160,8 / p95 178,4 / max 179,1 мс; после — p50 48,8 / p95 89,3 / max 90,6 мс. При master 0.35 отношение PCM ровно 0.5000 (0.175), двойного ослабления нет.
- События, первый приватный прогон: event sink 1.0, шина 1.0, выход маршрута и задний sink до громкости 0.46952, задний sink после громкости 0.16809 при линейной громкости 0.358; корреляция с WAV 0.99839.
- События, отдельный полный прогон при master 0.23: event sink 1.0, шина 1.0, выход маршрута 0.183034, задний sink после громкости 0.06553 — около 6,6 % (−23,7 дБ) от event sink. ESS: accepted/enqueued/rendered 567/567/567, dropped 0, WAV ready 53/53.

## Границы

- Физическая слышимость и вибрация не проверены: усилитель, кабель, фактическое подключение разъёма и чувствительность вибродинамика не измерялись. Малое отношение после громкости — правдоподобный вклад, а не доказанная причина. Исправление событий не заявляется.
- Все звуковые проверки выполнены в приватных PipeWire-сессиях с виртуальными sink; живой конфиг и пользовательский сеанс не изменялись.
- Пакеты не устанавливались, расширение не включалось, сеанс GNOME не перезапускался. Установку выполняет пользователь по `build/release-staging/INSTALL.txt`.
- Для любых последующих аппаратных проверок верхний предел выхода вибродинамика — 35 %. Это ограничение, а не требование повысить громкость.
